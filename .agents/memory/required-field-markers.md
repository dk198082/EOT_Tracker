---
name: Required field markers
description: App-wide required-field labels must use a red asterisk, including conditional requirements.
---

Every required input in the app must have a red asterisk on its label. Apply
this to workflow actions, output editing, request forms, comments, and admin
settings. Conditional inputs are marked when they become required, such as
Risk Notes for High risk and reviewer selections for included steps.

**Why:** On 2026-10-02, the user explicitly asked for an app-wide convention:
"Any time there is a required field, it needs to have a red *".

**How to apply:** Use the shared required marker or required-label support.
Derive required status from each form's actual validation, not whether a field
was required in a different context. Do not mark optional/read-only data as
requiring new input or assign default risk scores to historical records.
